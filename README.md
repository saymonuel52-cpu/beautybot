# Бот для автоматической записи клиентов на услуги

## Описание проекта
AI-ассистент (чат-бот) для мастера, который автоматизирует запись клиентов через Telegram и ВКонтакте.

## Основные функции
- Диалоговая запись клиентов
- Гибкое расписание
- Учет статуса клиента
- Допуслуги (soft cross-sell)
- Напоминания о записи
- Интеграция с календарем

## Технологии
- Node.js
- Telegraf (Telegram API)
- VK-IO (VK API)
- Google Sheets API
- Google Calendar API
