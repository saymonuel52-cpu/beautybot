## Основные компоненты

### 1. NotificationService класс (src/services/notifications.js)

#### Инициализация:
- Настройка Google Calendar интеграции
- Загрузка шаблонов сообщений
- Инициализация очереди уведомлений

#### Типы уведомлений:
- Напоминания о записи (24 часа и 2 часа до визита)
- Подтверждения записи
- Чек-листы подготовки
- Запросы отзывов
- Уведомления об открытии записи

### 2. Структура уведомлений

#### Уведомление:
```javascript
notification = {
  id: 'reminder_24h_booking_1234567890',
  userId: 'tg_123456789', // или 'vk_123456789'
  type: 'reminder_24h', // или 'reminder_2h', 'checklist', 'review'
  message: 'Текст уведомления',
  scheduledAt: '2026-01-09T12:30:00Z',
  sent: false,
  retries: 0
}
```

#### Очередь уведомлений:
```javascript
notificationsQueue = [
  {
    id: 'reminder_24h_booking_1234567890',
    scheduledAt: '2026-01-09T12:30:00Z',
    notification: { /* объект уведомления */ }
  }
]
```

### 5. Типы уведомлений

#### Напоминание за 24 часа:
```
Здравствуйте, {имя}! Напоминаем, что завтра ({дата}) в {время} у вас запланирована процедура {услуга}.

Просьба отменить запись не позднее, чем за 12 часов до начала процедуры.
```

#### Напоминание за 2 часа:
```
Здравствуйте, {имя}! Напоминаем, что через 2 часа у вас запланирована процедура {услуга}.

Ждем вас в салоне красоты Светланы Соловьевой!
```

#### Чек-лист подготовки:
```
Для подготовки к процедуре {услуга} рекомендуем:

1. За 24 часа до процедуры не употребляйте алкоголь
2. За 3-4 часа до процедуры не ешьте жирную и острую пищу
3. Примите душ перед процедурой
...
```

#### Запрос отзыва:
```
Спасибо, {имя}, что доверили нам свою красоту!

Будем рады видеть вас снова. Если вам понравилось, пожалуйста, оставьте отзыв о нашей работе.

Хотите записаться на следующую процедуру?
```

#### Уведомление об открытии записи:
```
Здравствуйте, {имя}!

Рады сообщить, что открылась запись на ближайшие дни. Мы будем рады видеть вас у нас!

Хотите записаться на процедуру?
```

### Ошибки отправки:
