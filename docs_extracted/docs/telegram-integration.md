# Интеграция с Telegram

## Общая архитектура

```
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│   Telegram      │    │   Telegram Bot   │    │   Main App       │
│   (API)         │◄──►│   (Telegraf)     │◄──►│   (Node.js)      │
└─────────────────┘    └──────────────────┘    └──────────────────┘
                                │                       │
                                ▼                       ▼
                    ┌──────────────────┐    ┌──────────────────┐
                    │   Session        │    │   Services       │
                    │   Manager       │    │   (Scheduler,   │
                    └──────────────────┘    │   Notification,  │
                                            │   etc.)          │
                                            └──────────────────┘
```

## Основные компоненты

### 1. TelegramBot класс (src/bot/telegram.js)

#### Инициализация:
- Создание экземпляра Telegraf с токеном
- Настройка middleware для логирования
- Настройка команд и callback-запросов

#### Middleware:
- Логирование всех сообщений
- Проверка статуса пользователя
- Управление сессией пользователя

#### Команды:
- `/start` - Приветствие и запрос имени
- `/help` - Справочная информация
- `/cancel` - Отмена текущей операции

#### Обработка сообщений:
- Текстовые сообщения
- Callback-запросы
- Обработка ввода имени
- Показ меню услуг
- Обработка выбора услуги
- Обработка выбора времени
- Подтверждение записи

### 2. Структура сообщений

#### Приветствие:
```
Здравствуйте! Рады видеть вас в нашем салоне красоты. Меня зовут Светлана Соловьева, и я помогу вам записаться на процедуру.

Пожалуйста, представьтесь, как к вам обращаться?
```

#### Меню услуг:
```
Пожалуйста, выберите услугу, на которую вы хотели бы записаться:

[Шугаринг]
[Комплексы (шугаринг)]
[Аппаратные процедуры]
[Абонементы]
```

#### Inline-кнопки:
- Callback data формат: `service_{type}_{key}`
- Пример: `service_sugaring_deep_bikini`

### 3. Управление сессией

#### Данные сессии:
```javascript
ctx.session = {
  user: {
    id: ctx.from.id,
    name: ctx.from.first_name,
    isReturning: false,
    lastService: null
  },
  state: 'waiting_for_name', // или 'selecting_service', 'selecting_time', etc.
  selectedServiceType: null,
  selectedServiceKey: null,
  selectedTime: null
}
```

### 4. Обработка callback-запросов

#### Типы callback-запросов:
- `service_{type}` - Выбор категории услуг
- `service_{type}_{key}` - Выбор конкретной услуги
- `time_{date}_{time}` - Выбор времени
- `new_user` - Новый клиент
- `returning_user` - Постоянный клиент
- `confirm` - Подтверждение записи
- `cancel` - Отмена операции

### 5. Отправка сообщений

#### Текстовые сообщения:
```javascript
ctx.reply('Текст сообщения');
```

#### Сообщения с кнопками:
```javascript
ctx.reply('Текст сообщения', {
  reply_markup: {
    inline_keyboard: [
      [
        { text: 'Кнопка 1', callback_data: 'data_1' }
      ],
      [
        { text: 'Кнопка 2', callback_data: 'data_2' }
      ]
    ]
  }
});
```

#### Редактирование сообщений:
```javascript
ctx.editMessageText('Новый текст', {
  reply_markup: {
    inline_keyboard: [...]
  }
});
```

## Развертывание

### Переменные окружения:
```
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_WEBHOOK_URL=https://ваш-домен.com/telegram/webhook
```

### Docker:
```dockerfile
FROM node:16
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["npm", "start"]
```

### Docker Compose:
```yaml
version: '3'
services:
  bot:
    build: .
    ports:
      - "3000:3000"
    environment:
      - TELEGRAM_BOT_TOKEN=${TELEGRAM_BOT_TOKEN}
