# Схема диалога с клиентом

## Общая структура диалога

```
1. Приветствие
   ↓
2. Получение имени
   ↓
3. Определение статуса клиента (новый/постоянный)
   ↓
4. Выбор услуги
   ↓
5. Выбор времени
   ↓
6. Подтверждение записи
   ↓
7. Отправка чек-листа
   ↓
8. Напоминания (24 часа и 2 часа до визита)
   ↓
9. После процедуры (запрос отзыва)
```

## 1. Приветствие

**Сообщение:**
```
Здравствуйте! Рады видеть вас в нашем салоне красоты. Меня зовут Светлана Соловьева, и я помогу вам записаться на процедуру.

Пожалуйста, представьтесь, как к вам обращаться?
```

**Действие пользователя:**
- Ввод имени

## 2. Получение имени

**Сообщение (после ввода имени):**
```
Спасибо, {имя}! Рады видеть вас снова.

Вы уже были у нас ранее или это ваш первый визит?
```

**Кнопки:**
- [Новый клиент]
- [Постоянный клиент]

## 3. Определение статуса клиента

### Для нового клиента:

**Сообщение:**
```
Спасибо, {имя}! Рады приветствовать вас в нашем салоне.

Для вашего первого визита мы подготовили чек-лист с рекомендациями по подготовке к процедуре. После записи я отправлю его вам.
```

### Для постоянного клиента:

**Сообщение:**
```
Спасибо, {имя}! Рады видеть вас снова.

Как обычно, вы хотите записаться на {последняя услуга} или попробовать что-то новенькое?
```

**Кнопки:**
- [Повторить {последняя услуга}]
- [Выбрать другую услугу]

## 4. Выбор услуги

**Сообщение:**
```
Пожалуйста, выберите услугу, на которую вы хотели бы записаться:
```

**Категории услуг:**
- [Шугаринг]
- [Комплексы (шугаринг)]
- [Аппаратные процедуры]
- [Абонементы]

### Подкатегории:

#### Шугаринг:
- Лицо (15 мин, 300 руб)
- Верхняя губа (10 мин, 200 руб)
- Подмышки (15 мин, 400 руб)
- Руки (30 мин, 700 руб)
- Ноги (45 мин, 1200 руб)
- Глубокое бикини (30 мин, 1000 руб)
- Поясница/ягодицы/живот (45 мин, 1500 руб)

#### Комплексы (шугаринг):
- Бикини + подмышки (60 мин, 1800 руб)
- Бикини + подмышки + ноги (90 мин, 2500 руб)

#### Аппаратные процедуры:
- LPG (30 мин, 1500 руб)
- Кавитация (30 мин, 1200 руб)
- RF-лифтинг (45 мин, 2000 руб)
- Вакуумный массаж (30 мин, 1000 руб)

#### Абонементы:
- Запрос информации о доступных абонементах

## 5. Предложение дополнительной услуги

**Сообщение (после выбора основной услуги):**
```
Отличный выбор! 

Могу предложить вам также {дополнительная услуга} всего за {цена} руб. Это прекрасное дополнение к вашей основной процедуре.

Хотите добавить?
```

**Кнопки:**
- [Да, добавить]
- [Нет, спасибо]

## 6. Выбор времени

**Сообщение:**
```
Пожалуйста, выберите удобное время для вашей процедуры:
```

**Доступные даты (только свободные окна):**
- [10.01.2026]
- [11.01.2026]
- [12.01.2026]
- [13.01.2026]
- [14.01.2026]

### Выбор времени в конкретный день:

**Сообщение:**
```
Выберите время на 10.01.2026:
```

**Доступные временные слоты:**
- [10:00]
- [11:00]
- [14:30]
- [15:30]
- [16:30]
- [17:30]
- [18:30]
- [19:30]

## 7. Подтверждение записи

**Сообщение:**
```
{name}, вы записаны на {услуга} {дата} в {время}.

Длительность процедуры: {длительность} мин.
Стоимость: {цена} руб.

Подтвердить запись?
```

**Кнопки:**
- [Подтвердить запись]
- [Выбрать другое время]
- [Отмена]

## 8. После подтверждения

**Сообщение:**
```
Спасибо, {имя}! Вы успешно записаны на процедуру.

Чек-лист с рекомендациями по подготовке отправлен вам в личные сообщения.

Напоминаем, что процедура состоится {дата} в {время}.
Напоминание о визите придет за 24 часа и за 2 часа до процедуры.
```

## 9. Напоминания

### Напоминание за 24 часа:

**Сообщение:**
```
Здравствуйте, {имя}! Напоминаем, что завтра ({дата}) в {время} у вас запланирована процедура {услуга}.

Просьба отменить запись не позднее, чем за 12 часов до начала процедуры.
```

### Напоминание за 2 часа:

**Сообщение:**
```
Здравствуйте, {имя}! Напоминаем, что через 2 часа у вас запланирована процедура {услуга}.

Ждем вас в салоне красоты Светланы Соловьевой!
```

## 10. После процедуры

**Сообщение:**
```
Спасибо, {имя}, что доверили нам свою красоту!

Будем рады видеть вас снова. Если вам понравилось, пожалуйста, оставьте отзыв о нашей работе.

Хотите записаться на следующую процедуру?
```

**Кнопки:**
- [Да, записаться]
- [Позже]
- [Оставить отзыв]

## Обработка ошибок

### Недоступное время:

**Сообщение:**
```
Извините, выбранное время уже занято. Пожалуйста, выберите другое время.
```

### Отмена записи:

**Сообщение:**
```
Вы уверены, что хотите отменить запись на {услуга} {дата} в {время}?

Пожалуйста, подтвердите отмену.
```

**Кнопки:**
- [Да, отменить]
- [Нет, оставить]

### Перенос записи:

**Сообщение:**
```
Вы хотите перенести запись на {услуга} с {старая дата} в {старое время} на другое время?

Пожалуйста, выберите новое время из доступных вариантов.
```

## Режим отпуска / перерыва

**Сообщение (если нет свободных окон > 3 дней):**
```
Спасибо за ваш интерес к нашим услугам!

К сожалению, все специалисты заняты в ближайшие дни. Мы открыли предварительную запись на следующую неделю.

Хотите, чтобы мы уведомили вас, когда откроются новые окна для записи?
```

**Кнопки:**
- [Да, уведомить]
- [Нет, спасибо]
