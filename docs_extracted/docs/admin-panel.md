# Админ-панель для управления

## Общая архитектура

```
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│   Admin Panel   │    │   Main App       │    │   Google Sheets  │
│   (Web UI)      │◄──►│   (Node.js)      │◄──►│   (Data Store)    │
└─────────────────┘    └──────────────────┘    └──────────────────┘
        │                       │                       │
        ▼                       ▼                       ▼
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│   Dashboard     │    │   API Endpoints  │    │   Schedule Data │
│   (React)       │    │   (Express)     │    │   (Google API)   │
└─────────────────┘    └──────────────────┘    └──────────────────┘
```

## Основные компоненты

### 1. Веб-интерфейс админ-панели

#### Технологии:
- Frontend: React.js с Material-UI
- Backend: Express.js REST API
- Аутентификация: JWT токены
- Хостинг: Статический хостинг (например, Vercel/Netlify)

#### Структура интерфейса:
- Дашборд с основными метриками
- Управление расписанием
- Просмотр и управление записями
- Управление услугами и ценами
- Настройки уведомлений
- Просмотр отзывов

### 2. Аутентификация и безопасность

#### Вход в систему:
```
Логин: admin@salon.ru
Пароль: [защищенный паролем]
```

#### JWT токены:
- Срок действия: 24 часа
- Обновление токенов
- Защита от CSRF атак

#### Роли пользователей:
- Администратор (полный доступ)
- Мастер (ограниченный доступ)

### 3. Дашборд

#### Основные метрики:
- Количество записей за день/неделю/месяц
- Доход по услугам
- Загрузка по дням недели
- Отзывы клиентов

#### Графики и диаграммы:
- График загрузки по дням
- Диаграмма популярных услуг
- График доходов по месяцам
- Рейтинг удовлетворенности клиентов

#### Быстрые действия:
- [Добавить запись вручную]
- [Отправить уведомление всем]
- [Экспорт данных в Excel]

### 4. Управление расписанием

#### Редактирование рабочих дней:
```
Понедельник: [x] Рабочий день 09:00 - 20:00
Вторник: [x] Рабочий день 09:00 - 20:00
Среда: [x] Рабочий день 09:00 - 20:00
Четверг: [x] Рабочий день 09:00 - 20:00
Пятница: [x] Рабочий день 09:00 - 20:00
Суббота: [x] Рабочий день 09:00 - 20:00
Воскресенье: [ ] Выходной
```

#### Управление перерывами:
```
Обеденный перерыв: 13:00 - 14:00
```

#### Отпуск и нерабочие периоды:
```
С 20.01.2026 по 30.01.2026 - отпуск
```

#### Синхронизация с Google Sheets:
- Автоматическая синхронизация каждые 5 минут
- Ручная синхронизация по кнопке
- Лог синхронизации

### 5. Управление записями

#### Просмотр записей:
- Фильтрация по дате
- Фильтрация по статусу (подтверждена/отменена)
- Поиск по имени клиента
- Сортировка по дате/времени

#### Действия с записями:
- [Подтвердить запись]
- [Отменить запись]
- [Перенести запись]
- [Отправить напоминание]

#### Добавление записи вручную:
Форма с полями:
- Имя клиента
- Телефон клиента
- Услуга
- Дата и время
- Комментарий

### 6. Управление услугами и ценами

#### Список услуг:
```
Шугаринг:
  Лицо: 15 мин, 300 руб
  Верхняя губа: 10 мин, 200 руб
  Подмышки: 15 мин, 400 руб
  ...

Комплексы:
  Бикини + подмышки: 60 мин, 1800 руб
  ...

Аппаратные процедуры:
  LPG: 30 мин, 1500 руб
  ...
```

#### Редактирование услуг:
- Название услуги
- Длительность (минуты)
- Цена (рубли)
- Категория услуги

#### Импорт/экспорт прайса:
- Импорт из Excel/Google Sheets
- Экспорт в Excel
- История изменений цен

### 7. Настройки уведомлений

#### Время напоминаний:
```
Первое напоминание: за [24] часов до визита
Второе напоминание: за [2] часов до визита
```

#### Тексты уведомлений:
- Редактор шаблонов сообщений
- Предпросмотр сообщений
- Персонализированные переменные

#### Настройки каналов:
- Включение/отключение Telegram
- Включение/отключение VK
- Настройки Google Calendar

### 8. Управление отзывами

#### Просмотр отзывов:
- Список всех отзывов
- Фильтрация по дате
- Поиск по имени клиента
- Сортировка по рейтингу

#### Ответы на отзывы:
- Форма для ответа на отзыв
- Шаблоны ответов
- История ответов

#### Статистика отзывов:
- Средний рейтинг
- Количество отзывов по месяцам
- Анализ ключевых слов

### 9. Настройки интеграций

#### Google Sheets:
- ID таблицы
- Email клиента Google
- Приватный ключ
- Тест подключения

#### Google Calendar:
- ID календаря
- Настройки синхронизации
- Тест подключения

#### Telegram:
- Токен бота
- Вебхук URL
- Тест подключения

#### VK:
- Токен группы
- ID группы
- Тест подключения

### 10. Логирование и мониторинг

#### Логи активности:
- Все действия администратора
- Изменения в расписании
- Отправка уведомлений
- Ошибки системы

#### Мониторинг:
- Статус подключений
- Загрузка системы
- Ошибки интеграций
- Уведомления о проблемах

#### Экспорт логов:
- Экспорт в CSV
- Фильтрация по дате
- Поиск по ключевым словам

## API Endpoints

### Аутентификация:
```
POST /api/auth/login
POST /api/auth/logout
POST /api/auth/refresh
```

### Расписание:
```
GET /api/schedule
PUT /api/schedule
GET /api/schedule/bookings
POST /api/schedule/bookings
PUT /api/schedule/bookings/:id
DELETE /api/schedule/bookings/:id
```

### Услуги:
```
GET /api/services
POST /api/services
PUT /api/services/:id
DELETE /api/services/:id
```

### Уведомления:
```
GET /api/notifications
POST /api/notifications/send
GET /api/notifications/templates
PUT /api/notifications/templates/:id
```

### Отзывы:
```
GET /api/reviews
POST /api/reviews/:id/reply
PUT /api/reviews/:id/status
```

### Настройки:
```
GET /api/settings
PUT /api/settings
GET /api/settings/integrations
PUT /api/settings/integrations
```

## Безопасность

### Защита API:
- Rate limiting (100 запросов в минуту)
- CORS настройки
- Валидация входных данных
- Логирование подозрительной активности

### Защита данных:
- Шифрование конфиденциальных данных
- Регулярное резервное копирование
- Аудит доступа к данным

## Развертывание

### Docker:
```dockerfile
FROM node:16
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3001
CMD ["npm", "start"]
```

### Docker Compose:
```yaml
version: '3'
services:
  admin-panel:
    build: ./admin-panel
    ports:
      - "3001:3001"
    environment:
      - JWT_SECRET=${JWT_SECRET}
      - GOOGLE_SHEET_ID=${GOOGLE_SHEET_ID}
```

### Переменные окружения:
```
JWT_SECRET=ваш_секретный_ключ
ADMIN_EMAIL=admin@salon.ru
ADMIN_PASSWORD=ваш_пароль
GOOGLE_SHEET_ID=ваш_id_таблицы
