# Чат-бот для автоматической записи клиентов на услуги салона красоты

## Техническое задание

### 1. Общее описание
Создать AI-ассистента (чат-бота) для мастера, который автоматизирует запись клиентов через Telegram и ВКонтакте, ведёт диалог в тёплом, формальном, лаконичном тоне и полностью заменяет ручные ответы на первичные запросы.

### 2. Каналы интеграции
- Telegram (бот в личные сообщения)
- ВКонтакте (через сообщения сообщества или личные сообщения)

### 3. Основные функции
- Диалоговая запись с приветствием, запросом имени, выбором услуги, уточнением статуса клиента, выбором времени и подтверждением
- После записи: автоматическая отправка чек-листа подготовки
- Два напоминания: за 24 часа и за 2 часа до визита
- После процедуры: мягкая просьба об отзыве и предложение поделиться
- Гибкое расписание с возможностью задания свободных окон через Google Sheets, Tilda-форму или админку
- Бот показывает только доступные даты и время с поддержкой перерывов и выходных
- Учёт статуса клиента: новичок (расширенный чек-лист) или постоянный (предложение повторить прошлую услугу)
- Допуслуги (soft cross-sell) с одним логичным предложением после выбора основной услуги
- Правила отмены с предупреждением о возможности переноса записи за 12 часов
- Режим отпуска / перерыва с предложением уведомить об открытии записи при отсутствии свободных окон > 3 дней
- Отображение цен и длительности при выборе услуги

### 4. Стиль общения
- Формально: «Здравствуйте», «Благодарю», чёткая структура
- Мило: лёгкие эмоции (✔, ✖), слова «рады», «с нетерпением», «спасибо, что доверяете»
- Лаконично: без «воды»
- Имя клиента используется во всех сообщениях после первого ответа

### 5. Список услуг
- Шугаринг: лицо, верхняя губа, подмышки, руки, ноги, глубокое бикини, поясница/ягодицы/живот
- Комплексы (шугаринг): бикини + подмышки, бикини + подмышки + ноги и др.
- Аппаратные процедуры: LPG, кавитация, RF-лифтинг, вакуумный массаж
- Абонементы — по запросу

### 6. Дополнительно
- Синхронизация с Google Calendar / Яндекс.Календарь
- Админ-панель или Google Таблица для управления расписанием
- Безопасность: бот не имеет доступа к личной переписке мастера
- White-label: бот говорит от лица мастера (имя: Светлана Соловьева)

## Реализация проекта

### Архитектура системы

Проект построен на модульной архитектуре с четким разделением компонентов:

```
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│   Telegram Bot  │    │     VK Bot       │    │   Web Admin      │
│   (Telegraf)    │    │     (VK-IO)      │    │    Panel         │
└─────────┬───────┘    └────────┬─────────┘    └────────┬─────────┘
          │                     │                       │
          └─────────────────────┼───────────────────────┘
                                │
                    ┌───────────▼───────────┐
                    │     Main App          │
                    │   (Node.js/Express)    │
                    └───────────┬───────────┘
                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
┌───────▼────────┐    ┌───────▼────────┐    ┌───────▼────────┐
│  Scheduler     │    │ Notification  │    │ Google Sheets  │
│  Service       │    │  Service       │    │  Service       │
│                │    │                │    │                │
│ - Time slots   │    │ - Reminders    │    │ - Schedule     │
│ - Booking      │    │ - Checklists   │    │ - Bookings     │
│ - Availability │    │ - Reviews      │    │ - Prices        │
└────────────────┘    └────────────────┘    └────────────────┘
```

### Основные компоненты системы

#### 1. Боты (Bots)
- **Telegram Bot**: Обработка сообщений через Telegram с использованием библиотеки Telegraf
- **VK Bot**: Обработка сообщений через ВКонтакте с использованием библиотеки VK-IO

#### 2. Основное приложение (Main App)
- **Orchestrator**: Координация работы всех компонентов
- **Session Manager**: Управление сессиями пользователей
- **Dialog Manager**: Управление диалогами с клиентами

#### 3. Сервисы (Services)
- **Scheduler Service**: Управление расписанием и бронированием
- **Notification Service**: Отправка уведомлений и чек-листов
- **Google Sheets Service**: Интеграция с Google Sheets для данных

#### 4. Конфигурация (Configuration)
- **Services Config**: Список услуг, цен, длительности
- **Messages Config**: Шаблоны сообщений
- **Checklists Config**: Чек-листы для подготовки

## Функциональные возможности

### Диалоговая система записи

Процесс записи клиента проходит через следующие этапы:
1. Приветствие и запрос имени
2. Определение статуса клиента (новый/постоянный)
3. Выбор услуги из доступных категорий
4. Предложение дополнительной услуги (soft cross-sell)
5. Выбор даты и времени из доступных слотов
6. Подтверждение записи с отправкой чек-листа

### Система управления расписанием

- Гибкое расписание с настройкой рабочих дней и часов
- Поддержка перерывов и выходных дней
- Автоматическая генерация временных слотов
- Интеграция с Google Sheets для хранения расписания
- Проверка доступности слотов в реальном времени

### Система уведомлений

- Напоминания за 24 часа и за 2 часа до визита
- Автоматическая отправка чек-листов подготовки
- Запросы отзывов после процедуры
- Уведомления об открытии записи в режиме отпуска
- Интеграция с Google Calendar

### Управление клиентами

- Определение статуса клиента (новый/постоянный)
- Персонализированные чек-листы в зависимости от типа клиента
- История записей и услуг
- Предложения на основе предыдущих визитов

### Админ-панель

- Дашборд с основными метриками
- Управление расписанием
- Просмотр и управление записями
- Управление услугами и ценами
- Настройки уведомлений
- Просмотр отзывов

## Технические детали

### Технологии

- **Backend**: Node.js
- **Telegram API**: Telegraf
- **VK API**: VK-IO
- **Google Integration**: Google APIs (Sheets, Calendar)
- **Frontend**: React.js (для админ-панели)
- **Database**: Google Sheets
- **Deployment**: Docker, PM2

### Хранение данных

Все данные хранятся в Google Sheets с следующей структурой:

1. **Schedule Sheet**: Расписание работы
2. **Bookings Sheet**: Бронирования клиентов
3. **Services Sheet**: Услуги и цены
4. **Clients Sheet**: Информация о клиентах

### Безопасность

- Все токены и ключи хранятся в переменных окружения
- Доступ к Google Sheets ограничен необходимыми правами
- Логирование активности пользователей для мониторинга

## Развертывание

### Локальное развертывание

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Настройка переменных окружения в файле `.env`

3. Запуск приложения:
   ```bash
   npm start
   ```

### Развертывание на сервере

Проект поддерживает развертывание через:
- Docker и Docker Compose
- PM2 на VPS
- Heroku

### Требования

- Node.js 16+
- Доступ к Google Cloud проекту
- Боты в Telegram и VK
- Google Sheets таблица

## Заключение

Созданный чат-бот полностью соответствует техническому заданию и предоставляет мастеру мощный инструмент для автоматизации записи клиентов. Система работает 24/7, снижает нагрузку на мастера и повышает лояльность и явку клиентов.

Проект готов к немедленному развертыванию и использованию в реальных условиях работы салона красоты.
