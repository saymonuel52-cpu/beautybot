## Основные компоненты системы

### 1. Боты (Bots)
- **Telegram Bot**: Обработка сообщений через Telegram
- **VK Bot**: Обработка сообщений через ВКонтакте

### 2. Основное приложение (Main App)
- **Orchestrator**: Координация работы всех компонентов
- **Session Manager**: Управление сессиями пользователей
- **Dialog Manager**: Управление диалогами с клиентами

### 3. Сервисы (Services)
- **Scheduler Service**: Управление расписанием и бронированием
- **Notification Service**: Отправка уведомлений и чек-листов
- **Google Sheets Service**: Интеграция с Google Sheets для данных

### 4. Конфигурация (Configuration)
- **Services Config**: Список услуг, цен, длительности
- **Messages Config**: Шаблоны сообщений
- **Checklists Config**: Чек-листы для подготовки

## Поток данных

1. **Получение сообщения**:
   - Пользователь отправляет сообщение через Telegram или VK
   - Бот получает сообщение и передает в Main App

2. **Обработка сообщения**:
   - Main App определяет тип сообщения и текущее состояние пользователя
   - Вызывает соответствующие сервисы для обработки

3. **Диалог с пользователем**:
   - Dialog Manager управляет состоянием диалога
   - Отправляет пользователю соответствующие сообщения и кнопки

4. **Бронирование**:
   - Scheduler Service проверяет доступность времени
   - Создает бронирование и сохраняет в Google Sheets

5. **Уведомления**:
   - Notification Service планирует и отправляет уведомления
   - Отправляет чек-листы и запросы на отзывы

## Хранение данных

### Google Sheets структура:

1. **Schedule Sheet**:
   - Дни недели
   - Рабочее время
   - Перерывы

2. **Bookings Sheet**:
   - ID бронирования
   - ID пользователя
   - Имя пользователя
   - Услуга
   - Дата и время
   - Статус

3. **Services Sheet**:
   - Тип услуги
   - Название услуги
   - Длительность
   - Цена

4. **Clients Sheet**:
   - ID пользователя
   - Имя
   - Тип (новый/постоянный)
   - Последняя услуга
   - Дата последнего визита

## Масштабируемость

### Горизонтальное масштабирование:
- Каждый бот может работать независимо
- Сервисы могут быть разделены на микросервисы

### Вертикальное масштабирование:
- Увеличение количества одновременных сессий
- Расширение функционала уведомлений

## Безопасность

- Все токены и ключи хранятся в переменных окружения
- Доступ к Google Sheets ограничен необходимыми правами
- Логирование активности пользователей для мониторинга
