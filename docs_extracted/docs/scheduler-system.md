# Система управления расписанием

## Общая архитектура

```
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│   Scheduler     │    │   Google Sheets   │    │   Main App       │
│   Service       │◄──►│   Service        │◄──►│   (Node.js)      │
└─────────────────┘    └──────────────────┘    └──────────────────┘
        │                       │                       │
        ▼                       ▼                       ▼
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│   Time Slots    │    │   Schedule Data  │    │   Booking Data   │
```

## Основные компоненты

### 1. Scheduler класс (src/services/scheduler.js)

#### Инициализация:
- Загрузка расписания из Google Sheets
- Генерация временных слотов
- Настройка рабочих дней и перерывов

#### Расписание:
- Рабочие дни (понедельник-суббота)
- Время работы (09:00 - 20:00)
- Перерывы (13:00 - 14:00)
- Выходные (воскресенье)

#### Временные слоты:
- Генерация слотов по 30 минут
- Учет перерывов и рабочего времени
- Проверка доступности слотов

### 2. Структура данных

#### Расписание:

## Управление временными слотами

### Генерация слотов:
- Разделение рабочего дня на 30-минутные интервалы
- Исключение перерывов
- Учет продолжительности услуг

### Проверка доступности:
- Поиск свободных слотов
- Проверка пересечений с существующими бронированиями
- Учет продолжительности услуги

### Блокировка слотов:
- Блокировка при бронировании
- Автоматическая разблокировка при отмене
- Обновление статуса в реальном времени

## Режимы работы

### Рабочие дни:
- Понедельник-суббота: 09:00 - 20:00
- Воскресенье: выходной

### Перерывы:
- Обеденный перерыв: 13:00 - 14:00

### Праздничные дни:
- Загрузка из Google Sheets
- Автоматическое обновление расписания

## Уведомления о доступности

### Проверка доступности:
- Мониторинг свободных слотов
- Отправка уведомлений при открытии записи

### Режим отпуска:
- Проверка отсутствия свободных слотов > 3 дней
- Предложение уведомления об открытии записи
- Очередь уведомлений "notify_on_opening"
