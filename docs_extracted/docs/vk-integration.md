# Интеграция с ВКонтакте

## Общая архитектура

```
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│   VK API        │    │   VK Bot         │    │   Main App       │
│   (Long Poll)   │◄──►│   (VK-IO)        │◄──►│   (Node.js)      │
└─────────────────┘    └──────────────────┘    └──────────────────┘
                                │                       │
                                ▼                       ▼
                    ┌──────────────────┐    ┌──────────────────┐
                    │   Session        │    │   Services       │
                    │   Manager       │    │   (Scheduler,   │
                    └──────────────────┘    │   Notification,  │
                                            │   etc.)          │
                                            └──────────────────┘
```

## Основные компоненты

### 1. VKBot класс (src/bot/vk.js)

#### Инициализация:
- Создание экземпляра VK с токеном и ID группы
- Настройка Long Polling
- Настройка обработчиков сообщений

#### Обработка сообщений:
- Фильтрация исходящих сообщений
- Логирование входящих сообщений
- Управление сессией пользователя
- Обработка команд
- Обработка callback-кнопок

#### Команды:
- `start` - Приветствие и запрос имени
- Обработка текстовых сообщений

#### Callback-кнопки:
- Обработка payload данных
- Навигация по меню услуг
- Выбор времени записи

### 2. Структура сообщений

#### Приветствие:
```
Здравствуйте! Рады видеть вас в нашем салоне красоты. Меня зовут Светлана Соловьева, и я помогу вам записаться на процедуру.

Пожалуйста, представьтесь, как к вам обращаться?
```

#### Меню услуг:
```
Пожалуйста, выберите услугу, на которую вы хотели бы записаться:

[Шугаринг]
[Комплексы (шугаринг)]
[Аппаратные процедуры]
[Абонементы]
```

#### Inline-кнопки:
- Payload формат: `{"command": "service", "type": "sugaring"}`
- Пример: `{"command": "service_item", "type": "sugaring", "key": "deep_bikini"}`

### 3. Управление сессией

#### Данные сессии:
```javascript
context.session = {
  user: {
    id: context.senderId,
    name: null,
    isReturning: false,
    lastService: null
  },
  state: 'waiting_for_name', // или 'selecting_service', 'selecting_time', etc.
  selectedServiceType: null,
  selectedServiceKey: null,
  selectedTime: null
}
```

### 4. Обработка callback-кнопок

#### Типы payload:
- `{"command": "service", "type": "sugaring"}` - Выбор категории услуг
- `{"command": "service_item", "type": "sugaring", "key": "deep_bikini"}` - Выбор конкретной услуги
- `{"command": "back_to_services"}` - Возврат к меню услуг

### 5. Отправка сообщений

#### Текстовые сообщения:
```javascript
context.send('Текст сообщения');
```

#### Сообщения с кнопками:
```javascript
context.send({
  message: 'Текст сообщения',
  keyboard: {
    inline: true,
    buttons: [
      [
        {
          action: {
            type: 'text',
            label: 'Кнопка 1',
            payload: JSON.stringify({ command: 'action_1' })
          }
        }
      ]
    ]
  }
});
```

#### Клавиатура:
- Inline-кнопки для меню услуг
- Callback-кнопки для выбора времени
- Навигационные кнопки (назад, отмена)

## Настройка Callback API

### Установка Callback API:
1. Перейти в настройки группы ВКонтакте
2. Вкладка "Работа с API"
3. Включить Callback API
4. Указать URL сервера
5. Подтвердить сервер

### Обработка событий:
- `message_new` - Новое сообщение
- `message_reply` - Ответ на сообщение
- `message_edit` - Редактирование сообщения

## Развертывание

### Переменные окружения:
```
VK_TOKEN=ваш_токен
VK_GROUP_ID=ваш_id_группы
```

### Docker:
```dockerfile
FROM node:16
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["npm", "start"]
```

### Docker Compose:
```yaml
version: '3'
services:
  bot:
    build: .
    ports:
      - "3000:3000"
    environment:
      - VK_TOKEN=${VK_TOKEN}
      - VK_GROUP_ID=${VK_GROUP_ID}
